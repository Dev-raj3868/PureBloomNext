# PureBloomNext Shopify Theme

Custom Shopify theme files for the PureBloomNext storefront.

## Theme structure

- `assets/` — theme styles, scripts, and storefront images
- `config/` — theme settings and schema
- `layout/` — Shopify theme layout
- `locales/` — language files
- `sections/` — storefront sections
- `snippets/` — reusable Liquid snippets
- `templates/` — Shopify JSON templates

Upload this theme to Shopify from **Online Store → Themes → Add theme → Upload zip file** after packaging the repository contents as a ZIP.
